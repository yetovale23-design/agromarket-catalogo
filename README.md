# AgroMarket — Módulo Catálogo de Productos

Módulo del sistema AgroMarket, la plataforma web de comercialización
de productos agrícolas. Este repositorio contiene el desarrollo del
módulo "Catálogo de productos", encargado de listar los productos
agrícolas disponibles, permitir su filtrado por categoría y mostrar
el detalle de cada producto para que el comprador contacte al productor.
